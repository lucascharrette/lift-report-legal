# Lift Report legal pages

The published privacy policy and terms for the Lift Report iOS app.

These pages are **generated**. The source lives in the app repository at
`legal/privacy.md` and `legal/terms.md`, and is rendered here by
`legal/build.py`. Edit the markdown there, regenerate, and commit the result.
Editing the HTML directly means the next build silently reverts it.

This repository is public because GitHub Pages requires it on a free account.
It deliberately contains no application or server code.
